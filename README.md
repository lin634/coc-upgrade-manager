# 部落冲突升级管理 · COC Upgrade Manager

一款轻量的安卓倒计时助手:对着游戏截图识别剩余升级时间,自动建倒计时,到点强提醒。
支持多账号、多 AI 服务商、WebDAV 多设备同步,不需要 root,不需要抓包,不上传任何数据到第三方服务器。

> **下载 APK**:[Releases](https://github.com/lin634/coc-upgrade-manager/releases/latest) · 当前版本 **v1.8** · 要求 **Android 7.0+**

---

## 功能

| 功能 | 说明 |
|---|---|
| 📷 截图识别 | 从相册选一张带「剩余升级时间」的游戏截图,AI 识别出项目与时间,确认后一键建倒计时 |
| 👥 多账号 | 任意多个部落冲突账号,各自的倒计时列表互不干扰 |
| 🤖 多服务商 / 多模型 | 完全自定义,走 OpenAI 兼容协议;智谱、DeepSeek、通义千问、Kimi、OpenAI 或任意中转站都能接 |
| ⏰ 到点强提醒 | 系统通知横幅 + 提示音 + 震动;前台常驻服务 + AlarmManager,App 被杀掉也能准时响 |
| 🔁 重启自动恢复 | 开机广播重排所有未完成的提醒,重启手机不丢倒计时 |
| ☁️ 多设备同步 | WebDAV(推荐坚果云),数据存你自己的网盘,多台手机自动合并 |
| ⚡ 加速药水 | 建筑 2×/10×、兵种 2×/24×,按药水时长自动折算受影响项目的完成时间 |
| 🧹 列表管理 | 手动添加 / 编辑时间 / 多选删除 / 一键清除已完成 |

## 安装

1. 在 [Releases](https://github.com/lin634/coc-upgrade-manager/releases/latest) 下载最新 APK
2. 手机允许「安装未知来源应用」后安装
3. 首次启动按提示允许 **通知** 权限;如出现「闹钟和提醒」页面请允许,否则到点提醒可能延迟

## 快速开始

1. 右上角 **⚙ 模型设置** → 添加服务商:
   - 名称(自定义)、接口地址(`https://…/v1`)、API Key、模型名(逗号分隔)
   - 在「默认模型」中选一个**支持图片识别**的模型,例如 `glm-4.5v`、`qwen-vl-max`、`gpt-4o`
   - 点「测试连接」确认可用 →「保存并返回」
2. 主界面点 **＋账号**,输入角色名
3. 在游戏里截一张带剩余时间的图 → 回到 App 点 **📷 截图识别** → 从相册选图
4. 核对识别结果(可改行、删行、加行)→「确认添加」
5. 倒计时结束自动弹出通知

### 支持的截图格式

剩余时间文字越清晰识别率越高,常见写法都支持:

```
1d 2h        3天12小时      45m
12h 30m      2d           1天 6小时 20分
```

倒计时 = 添加时刻 + 剩余时间,中途关机、切后台都不影响准确性。

## 多设备同步(WebDAV)

1. 注册一个支持 WebDAV 的网盘(推荐 **坚果云**,免费额度够用):
   网页版 →「账户信息」→「安全选项」→「添加应用」→ 生成**应用密码**
2. App「⚙ 模型设置」底部「多设备同步」填写:
   - 文件地址:`https://dav.jianguoyun.com/dav/coc-upgrade.json`(文件名可自定)
   - 账号:坚果云注册邮箱
   - 密码:上一步生成的应用密码
3. 勾选「启用自动同步」→「立即同步」测试 →「保存并返回」
4. 第二台手机填入**相同**的地址与账号密码,数据自动互通

同步规则:

- 打开 App、数据变化时自动「下载 → 合并 → 上传」(全量同步,数据仅几 KB)
- 新增/修改按更新时间取较新者,删除会同步到所有设备
- 服务商配置会合并:同名服务商保留本地配置,缺失的字段与模型列表从远端补齐
- 到点提醒仍由每台设备各自触发,所以每台手机都会响

> ⚠️ 同步文件包含服务商 API Key(便于换机免重填)。请使用**私有** WebDAV 目录,不要公开分享该文件。

## 加速药水

主界面进入「⚡ 加速药水」,选择账号后:

1. 选择药水类型:建筑升级加速 / 兵种升级加速
2. 选择倍率:建筑 `2×`、`10×`;兵种 `2×`、`24×`
3. 填写药水时长(按瓶数,或自定义几小时几分钟)
4. 勾选这次药水能加速的项目 →「使用并加速」

App 会按「未来 N 小时内以 M 倍推进」换算每个项目的剩余时间,并重排提醒。只勾选药水真正作用的项目(建筑药水不加速兵种)。

## 权限说明

| 权限 | 用途 |
|---|---|
| 通知 | 到点提醒横幅 |
| 闹钟和提醒(SCHEDULE_EXACT_ALARM) | 精确定时,避免被系统延迟 |
| 开机自启(RECEIVE_BOOT_COMPLETED) | 重启后恢复倒计时 |
| 前台服务 | App 退到后台/被杀后仍能守时提醒 |
| 网络 | 调用 AI 接口、WebDAV 同步 |
| 震动 | 提醒时震动 |

## 数据与隐私

- 账号、倒计时、服务商配置全部保存在 App 私有目录(`data.json` / `config.json`),卸载即清除
- 截图只发给**你自己配置**的 AI 接口用于识别,不上传到其他服务器
- 未开启 WebDAV 时不做任何云端同步
- 仓库中不含任何 API Key

## 重新构建

需要 JDK 17+ 与 Android SDK(build-tools 35.0.0 + platform android-34):

```bash
cd android
bash build.sh
```

产物为上一级目录的 `部落冲突升级管理.apk`。脚本在缺失 `debug.keystore` 时会自动生成一个调试签名密钥。

> 调试密钥仅用于个人安装。若要正式分发,请自行生成 release keystore 并替换 `build.sh` 中的签名参数。

## 常见问题

**Q:识别结果为空或不准?**
换用支持视觉的模型(如 `glm-4.5v`、`qwen-vl-max`、`gpt-4o`),或截更清晰的图;也可以在识别结果页手动增删行。

**Q:到点没提醒?**
检查:通知权限、电池优化白名单、是否允许「闹钟和提醒」;部分系统需在应用设置里允许「自启动」。

**Q:卸载重装后数据没了?**
数据存在 App 私有目录,卸载即清除。先在旧设备开启 WebDAV 同步,新设备填相同配置即可恢复。

**Q:接口地址怎么填?**
填 OpenAI 兼容的 `…/v1` 根地址,App 会请求 `{base_url}/chat/completions`。

**Q:会封号吗?**
本 App 不读取游戏内存、不修改游戏数据、不自动操作游戏,只根据你自己提供的截图计算时间,理论上与游戏客户端无交互风险;但任何第三方工具都存在不确定性,请自行评估。
